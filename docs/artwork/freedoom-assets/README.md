# Настоящие предметы Freedoom для инспектора ресурсов

22 PNG извлечены из **Freedoom Phase 2 0.13.0**, `freedoom2.wad`, без установки
проприетарного Doom IWAD. Здесь используются оригинальные pickup-спрайты: восемь
типов боеприпасов/упаковок, три предмета лечения, три вида брони/бонусов, семь
видов оружия и особая награда. Это примеры ресурсов, а не новые параметры
индивидуального спавна каждого предмета.

Файлы находятся в `source_files/qt_frontend/assets/freedoom/`.
`manifest.json` связывает стабильный frontend ID с настоящим именем lump,
исходным размером, группой, русской подписью, параметром и SHA-256.
Сами PNG содержат исходные пиксели в исходном размере. Поля исходной patch canvas
не обрезаются, изображение не растягивается и не перекрашивается при извлечении.
В интерфейсе pixel art следует увеличивать с сохранением пропорций и без
сглаживания (`Image.PreserveAspectFit`, `smooth: false`).

[Контактный лист всех извлечённых предметов](contact-sheet.png).
Шахматный фон нанесён только на контактный лист для проверки прозрачности;
в PNG-ресурсах интерфейса он отсутствует.

## Воспроизведение

```sh
python3 scripts/dev/extract-freedoom-assets.py \
  --iwad /path/to/freedoom2.wad
python3 scripts/dev/extract-freedoom-assets.py --verify
```

Для этой облачной среды исходник находится в
`/workspace/.obsidian-art-tools/freedoom/usr/share/games/doom/freedoom2.wad`.
Скрипт использует только стандартную библиотеку Python: декодирует WAD directory,
Doom patch columns (включая tall-patch extension), первую PLAYPAL и записывает
детерминированные PNG RGBA8. Другие IWAD и версии отвергаются по контрольной сумме,
чтобы случайно не добавить чужие материалы или несовместимые палитры.

`--verify` не требует IWAD, Pillow, UZDoom, графического редактора или дисплея.
Проверяет полный каталог, ожидаемые подписи/группы, SHA-256 PNG и RGBA,
исходные размеры, PNG CRC и бинарную прозрачность. Встроенные self-checks
отвергают повреждённые pointers/posts и проверяют palette/transparency,
PNG round-trip и tall patch. Визуально проверены все 22 предмета на увеличенном
контактном листе: оружие, патроны, броня и аптечки узнаваемы; чёрного фона,
обрезанных столбцов, потерянной прозрачности и смещения палитры не обнаружено.
