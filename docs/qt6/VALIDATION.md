# Проверки миграции Qt 6

Проверены Debian 13 / Qt 6.8.2 и Ubuntu 24.04 / Qt 6.4.2 (контейнер).

- Основная сборка: Qt Quick GUI + CONSOLE_ONLY worker; FLTK не входит в эту сборку.
- QtTest: 8 функциональных сценариев, 10 passed с учётом setup/cleanup;
  без failed, skipped и expected-failure.
- Проверены legacy CONFIG round-trip, неизвестные параметры, ошибки импорта,
  бинарный и UDMF WAD, недопустимые ссылки/границы, реальная schema и генерация,
  обновление доступности при выборе Vanilla, seed в журнале worker,
  неизменность конфигурации между запусками, отмена и ошибка запуска worker.
- QML smoke: загрузка полного приложения с offscreen-платформой, создание WAD,
  чтение его геометрии и JSON-отчёт `qt-smoke.json`.
- Xvfb: настоящее окно, обе темы, генерация по F2, поиск, изменение размера,
  отдельный раздел результата и штатный выход. Проверяются отсутствие ошибок
  QML и сохранение seed/порта. Снимки в этой папке получены из приложения.
- Проверены сборка и упаковка Ubuntu. Пакет содержит оба бинарника, ресурсы,
  CHANGELOG, VERSION и launcher; библиотеки Qt устанавливаются из пакетов Ubuntu.

Полная геометрическая повторяемость seed не заявляется — прежняя FLTK-сборка
также показала разные результаты при одном полном CONFIG. Сохранены исходные
алгоритмы; [наблюдение](ENGINE_NOTES.md) включено в [план](../GENERATION_ROADMAP.md).

Windows/macOS, все игровые модули по отдельности, нативный Wayland и экранные
дикторы не проверены. Предпросмотр WAD не является проверкой проходимости.

## Studio 0.4.0

На Qt 6.8.2 / Linux завершены сборка, QtTest (12 passed, 0 failed, 0 skipped),
полная QML-генерация с seed 12345 и обе темы настоящего окна Xvfb.
Проверки включают категории без потерь/дубликатов, глобальный поиск расширенных
параметров, неизвестное дополнение и обновление при смене порта. QML diagnostics
в финальных dark/light launch.log пусты. Для инспектора дополнительно проверены
Ctrl+I, закрытие Escape и размер 1050×600. Скриншоты в этой папке обновлены
из работающего приложения, версия в них 0.4.0.

Подробности области аудита и ограничений: [STUDIO_AUDIT.md](STUDIO_AUDIT.md).
Ubuntu 24.04 / Qt 6.4.2 проверяется тем же набором в GitHub Actions, включая
сборку в каталоге `Obsidian source(1)`.
