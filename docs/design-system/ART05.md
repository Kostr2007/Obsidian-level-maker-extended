# ART-05: четыре оформления бегунка

Пользователь разрешил ART-05 с четырьмя вариантами. Окончательный выбор открыт.
Сохраняются ART-01=A, ART-02=A, ART-03=A и выбранный ART-04=B.

| Вариант | Гипотеза |
| --- | --- |
| A | Текущий нейтральный круг15×15 с существующей обводкой и фокусом. |
| B | Светлый непрозрачный диск19×19 с мягкой нейтральной границей. |
| C | Узкая светлая вертикальная капсула9×21. |
| D | Плоский акцентный квадрат16×16 со скруглением4. |

Размеры — исходные решения проекта для проверки, не спецификация Apple.
Источник B/C — изученные [HIG Sliders](https://developer.apple.com/design/human-interface-guidelines/sliders)
и реальные примеры; D — самостоятельная интерпретация цветных акцентов Obsidian.
Контракт ограничен числовым ползунком «Размер уровня» в `--design-preview`.
Трек, диапазон/шаг, точное поле, режимы значений и геометрия формы сохраняются.

Начальный бегунок — A. Переключение вариантов действует в текущем сеансе,
не добавляет ключей CONFIG и не меняет обычный Studio. Навигация запускается
с принятым ART-04 B. Все четыре варианта оцениваются до окончательного выбора.
