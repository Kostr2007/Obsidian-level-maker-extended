# ART-03: иерархия инспектора «Боеприпасы»

В ART-01 и ART-02 пользователь выбрал A: классическое выделение ресурсов
и полосатые строки настроек. Эти решения фиксированы в сравнении ART-03.

- **A:** исходный инспектор — галерея находится перед текущим значением.
- **B:** текущее значение находится после пояснения, перед галереей; галерея
  собрана на общей нейтральной подложке вместо отдельных фоновых плиток.

Это отдельный эксперимент только для «Ресурсы» → «Боеприпасы». Сохраняются
все восемь исходных спрайтов, подписи, два столбца, размеры/пропорции,
текущее значение и defaults, пояснения и уведомления об источнике. Основной
редактор, другие категории и обычный Studio сохраняют своё оформление.

```sh
./obsidian --design-preview
# Или из распакованной Ubuntu-сборки:
./start.sh --design-preview
```

Выберите «Ресурсы» → «Боеприпасы». В меню команд (`Ctrl+Shift+P`) доступны
варианты инспектора A/B для ART-03. A остаётся по умолчанию; выбор эксперимента
не записывается в CONFIG или пресеты. Окончательное решение по ART-03 открыто.

## Воспроизведение сравнения

```sh
./scripts/dev/build-linux.sh
python3 scripts/dev/check-art03.py
```

Нужны зависимости сборки, Qt Test и Xvfb. Сценарий снимает реальный
производственный QML отдельным QtTest-процессом в новый `build/art03/` каталог.
Матрица включает парные light/dark, текст125%, низ инспектора после прокрутки,
диалог инспектора на небольшом экране и HiDPI. Значения и состояния совпадают;
вертикальное перемещение блоков в B — ожидаемое изменение.

Metadata сохраняет точный коммит, hashes, viewport/DPR, выбранный параметр,
расположение текущего значения относительно галереи, источники/размеры
спрайтов и состояние фокуса/прокрутки. Проверки пользовательских сценариев
и отдельные заключения Visual Critic/Art Director прилагаются к результатам.
