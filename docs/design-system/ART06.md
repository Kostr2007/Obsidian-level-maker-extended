# ART-06: светлый фон инспектора

Пользователь разрешил ART-06 после проверки выбранной капсулы C в тёмной теме.
Приёмка C [подтверждена отдельным предшествующим шагом](reports/2026-11-07-art05-c-result.md).
Все варианты ART-06 сохраняют
ART-01 A, ART-02 A, ART-03 A, ART-04 B и принятую ART-05 C.

| Вариант | Светлый inline-инспектор |
| --- | --- |
| A | Исходный белый `#ffffff`. |
| B | Очень мягкий прохладный `#f7f8fa`. |
| C | Очень мягкий тёплый `#faf8f4`. |
| D | Более выраженный нейтральный `#e7e7eb`. |

Это гипотезы проекта, не обязательная палитра Apple. Во всех четырёх тёмная
панель остаётся прежней; модальный инспектор также не меняется. Сравнивается
только фон существующей правой панели Preview: сохраняются ширина, отступы,
текст, разделитель, восемь отдельных плиток боеприпасов и весь их порядок.
Начальный вариант A; переключение A/B/C/D действует в текущем сеансе.
Окончательный выбор остаётся за пользователем.
