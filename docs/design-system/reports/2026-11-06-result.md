## Решение

Проверенные состояния существующего дизайна приняты. Независимые аудиторы
не воспроизвели дефект продукта P0/P1/P2, требующий изменения QML. Крупный
редизайн по этим данным не назначен. Закрыта подтверждённая проблема P2
в доказательствах: снимок `game-dialog.png` раньше содержал страницу проекта
без диалога, хотя сценарий завершался успешно.

`ui_builder` воспроизвёл гонку: после Escape выпадающий список ещё закрывался
и поглощал немедленный Ctrl+G. Новый QtTest ждёт фактического `!popup.visible`,
открывает диалог, проверяет `opened`, `visible`, opacity 1 и готовый кадр перед
сохранением. Снимок создаётся отдельным тестовым процессом из того же
производственного QML. JSON фиксирует происхождение, коммит/чистоту дерева,
состояние, тему, масштаб, размеры и CONFIG. CI сохраняет эти данные.

Производственные QML/C++, алгоритмы генерации, IDs и поведение CONFIG
не изменялись. Сравнение `81cbc4f..c363ac1` подтверждает, что единственный
изменённый файл внутри frontend — `tests/test_core.cpp`.

## Ограничения

Локальные приёмочные проверки выполнены на Debian 13 / Qt 6.8.2 / Xvfb / software.
Ubuntu / Qt 6.4 проверяется отдельным прогоном GitHub Actions финальной ветки;
этот документ не заявляет его результат заранее. После последующих изменений
только отчётов/README код EV-01 сохраняется; CI создаёт артефакты своего точного SHA.

Screen reader/AT-SPI, нативные Wayland/macOS/Windows, реальная GPU-производительность
и поведение каждого возможного модуля не заявлены как проверенные. Apple motion
не изучался по движущемуся референсу; просмотренные Apple изображения статические.
Официальная документация и проектные решения разграничены. Apple-изображения,
SF-шрифты, символы и UI kit в репозиторий не включались.

Запрошенные high/medium переданы агентам явно. Фактические уровни исполнения
API не показывает: [проверка настроек](2026-11-06-agent-runtime.md) помечает их
UNVERIFIED. Это ограничение не скрыто за PASS конфигурационного валидатора.
