# ART-05: контракт четырёх вариантов

2026-11-07. Пользователь выбрал ART-04 B и разрешил ART-05 с четырьмя
вариантами вместо двух, с обновлением правил сравнений. Независимые отчёты
и окончательный выбор пользователя сохраняются в процессе.

## Ограниченный scope

В `--design-preview` менять оформление ручки числового ползунка «Размер уровня».
A — исходный нейтральный круг; B — светлый диск; C — вертикальная капсула;
D — акцентный скруглённый квадрат. Подробности и ссылки в art05-concepts.md.
Не распространять эксперимент на остальные слайдеры автоматически.

В том же шаге сделать уже выбранный ART-04 B начальным стилем навигации и
обновить ожидания старого теста/съёмки ART-04; его ручное A/B переключение
остаётся доступным. ART-01 classic, ART-02 zebra, ART-03 original фиксированы.
Изменять production QML может только UI Builder.

## Сохранить

- Трек и его заполнение, расположение поля и строки, исходное движение
  handle-wrapper, область взаимодействия. Разные рисунки центрируются в
  исходном wrapper, чтобы не менять implicit height и ход контрола.
- Настоящие min/max/step, значения и nan-режимы, мышь/drag, клавиатуру и
  точный ввод. Disabled-состояние должно оставаться очевидным и не принимать ввод.
- Существующий фокус A; B/C/D получают отличимый фокус, в том числе D с
  акцентной заливкой. Проверить крайние положения и отсутствие обрезки.
- Backend, генератор, CONFIG/preset round-trip, темы, другие параметры и Studio.

## Четырёхсторонняя проверка

Начальный slider style A; exclusive session-only A/B/C/D. Ни один новый вариант
не принимается автоматически. Общая рамка сравнения описана в WORKFLOW.md.

Снять **48** актуальных PNG: при DPR1 все4 варианта в light/dark для обычного
вида, клавиатурного фокуса, disabled-режима, окна900×540 и текста125%; при DPR1.5
обычный вид всех4 в обеих темах. Добавлять screenshot-сцены сверх этой матрицы
только для обнаруженной проблемы. Минимум/максимум, шаг и ввод проверяются
исполняемыми сценариями по всем4 вариантам; дополнительная съёмка — по риску.

Манифест: чистый commit/tree, source/app/test/PNG hashes, фактические значения,
режим/диапазон/шаг/enabled/focus, геометрия handle/wrapper/row/field/track/editor,
тема/viewport/DPR/text-scale, scroll и принятые стили. B/C/D сравниваются с A
по одинаковым данным и компоновке; изменение рисунка ручки ожидаемо. Проверка
source/historical исходного A должна честно отделять принятые B-значки от
собственно неизменённого слайдера (baseline f4ba69b Geometry с badges).

UI Builder (medium): QML + bounded QtTest capture/helper, build/core, предварительные
кадры и осмотр, без самоодобрения. Coordinator фиксирует код. Functional Tester
(medium): свежая съёмка с чистого commit, validator/build/core/Studio/Preview,
реальные действия всех4, CONFIG и запуск defaults. Visual Critic (high) и
Art Director (high): независимо текущие кадры всех4 + официальные примеры,
вердикт для каждого, сравнение и обоснованный порядок. Accessibility Critic
(medium): actual keyboard/focus/disabled/scale в пределах изменения.

После подтверждённой проблемы исправить и повторить затронутые gates на
новом commit; максимум3 итерации. Для четырёх вариантов не нужны шесть
попарных полных прогонов: достаточно одного общего baseline и проверки
каждой альтернативы. Все P0/P1 должны быть разрешены до представления.

Официальные Apple-картинки остаются временными исследовательскими материалами;
не копировать их в приложение или архив. Предыдущий каталог MAC-20 и полное
исследование HIG Sliders переиспользуются. ART-06 не входит в scope.
