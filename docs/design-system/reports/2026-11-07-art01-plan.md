# ART-01: план экспериментального сравнения

Пользователь утвердил только эксперимент ART-01. Основа — `881ab88`, отдельная
ветка `codex/art-01-resource-selection`. Окончательный выбор остаётся за пользователем.

## Варианты

- **A, исходный:** выбранная категория сохраняет синюю подложку названия.
- **B, ART-01:** подложка названия прозрачная, обычный цвет текста, усиленное
  начертание Inter того же размера. Фон выбранной карточки сохраняется.
- A остаётся вариантом по умолчанию. Переключение доступно в экспериментальном
  `--design-preview`, без изменения CONFIG, пресетов или обычного Studio.
- Keyboard focus должен иметь видимый контур; mouse hover, выбор категории и
  клавиатурный фокус проверяются как разные состояния.

## Работа и приёмка

1. `ui_builder` (medium) реализует ограниченный переключаемый прототип,
   регрессионные проверки и воспроизводимую съёмку. Только этот агент меняет QML.
2. Снимки A/B снимаются из одного коммита при одинаковых теме, размере, масштабе,
   выбранной категории, режиме сетка/список, фокусе и положении указателя.
   Минимум — восемь основных кадров: два варианта × две темы × два представления.
   Дополнительно проверяются keyboard focus, hover соседней категории, длинное
   название, увеличенный текст, HiDPI и небольшое окно.
3. `functional_tester` (medium) запускает обязательную сборку/Qt/Studio/Preview
   и сценарий ART-01. Проверяет мышь, стрелки, grid/list, выбор/инспектор,
   неизменность значений настроек, возврат к A и исходный A при новом запуске.
4. `visual_critic` (high) и `art_director` (high) независимо изучают парные
   текущие изображения и официальные референсы. До завершения отчётов
   заключения друг другу не передаются. Допускается предпочтение A.
5. `accessibility_critic` (medium) отдельно проверяет фокус, распознавание
   состояния, увеличенный текст и клавиатурную доступность переключения.
6. Координатор представляет изображения, отдельные заключения и ограничения
   пользователю. B не становится окончательным вариантом по итогам машинных
   или экспертных проверок без решения пользователя.

Максимум три итерации в рамках ART-01. Новые художественные направления,
«зебра», структура инспектора и игровые ассеты вне этого изменения.

## Конфигурация усилий

Корневая конфигурация запрашивает Ultra; профили специалистов явно содержат
Medium/High, и их уровни передаются в `reasoning_effort` при каждом новом запуске.
Название модели не меняется. Единое описание наблюдаемости остаётся в
[примечании среды](2026-11-06-agent-runtime.md).

## Подтверждённая сопутствующая проверка

При разработке обнаружено, что прежний вызов `forceActiveFocus()` после стрелки
передаёт active focus, но оставляет `visualFocus=false`. Регрессионный тест
воспроизвёл это до исправления. Разрешена узкая общая для A/B правка: навигация
стрелками передаёт keyboard focus reason; вход через мышь сохраняет прежнее
поведение. Это обеспечивает сопоставимую проверку видимого фокуса обоих вариантов.
