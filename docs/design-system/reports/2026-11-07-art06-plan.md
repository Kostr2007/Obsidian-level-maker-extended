# ART-06: контракт сравнения четырёх фонов

2026-11-07. Пользователь разрешил перейти к ART-06 после уточнения выбранной
капсулы C. Production ART06 начинается только после подтверждённых текущих
функциональных, визуальных и bounded accessibility-gates для этого уточнения.
Подготовленный контракт сам по себе не является приёмкой капсулы.

## Один визуальный параметр

Только light `inspectorPanel.color` в `--design-preview`: A#ffffff,
B#f7f8fa, C#faf8f4, D#e7e7eb. Использовать локальный цвет панели;
не менять глобальный `design.surface` или фон других компонентов. В dark
все4 совпадают с прежней поверхностью. Modal, Results, скрытая панель,
Studio, трек/капсула/форма и генератор не меняются.

Сохранить фактическую геометрию и порядок инспектора ART03A: отдельные8 плиток,
подписи, current/default, справку/атрибуцию/прокрутку. Новый фон не должен
маскировать выбранные элементы или содержимое изображений. D выбран с учётом
тёмного края отдельных светлых плиток; визуальную пригодность проверяют
эксперты, формула контраста контейнеров сама по себе не даёт PASS.

Принятые classic/zebra/original/badges/capsule фиксированы. Сеансовый exclusive
переключатель A/B/C/D для инспектора, defaultA, без CONFIG/preset-параметров.
Ни один из новых фонов не принимается автоматически. Все4 обязаны оставаться
доступными с клавиатуры в длинном меню с прокруткой.

## Матрица56 текущих кадров

При DPR1: normal Geometry, normal Ammo, bottom Ammo, large-text125% Ammo,
narrow900×540 Ammo modal — все4 в light/dark, итого40. При DPR1.5 normal
Geometry и Ammo — все4 в обеих темах, ещё16. Все состояния и значения внутри
четвёрки одинаковы, включая focus и scroll. Программно дополнительно проверить
скрытую панель, selection/resize/Return/Escape и fresh-launch defaults.

В light inline B/C/D меняют пиксели только в прямоугольнике правой панели;
metadata и все6 основных областей интерфейса сохраняют геометрию. В dark
и narrow modal все4 кадра должны полностью совпадать. Проверка цвета
по фактическим пикселям свободного фона вместе с source-token, без вывода
одной лишь метадаты. Все8 sprites/source/caption/painted sizes и подписи/default/
notice одинаковы; нижний кадр подтверждает достижимость конца содержимого.
Чистый commit/tree, исходники/app/test/PNG hashes, viewport/DPR/text-scale,
значение/focus/scroll и все accepted styles — в манифесте.

## Исполнение и независимая проверка

UI Builder (medium) — единственный production QML editor; один ограниченный
шаг, build/core, предварительная съёмка и осмотр. После commit Functional Tester
(medium) повторяет актуальную56-кадровую серию и обязательные проверки,
действительные меню/категории/клавиатуру/прокрутку/CONFIG/defaults. Старые ART01–05
матрицы повторяет CI; локально — затронутые случаи, не бесконечные полные прогоны.

Visual Critic (high) и Art Director (high) независимо рассматривают все4 в
одинаковых состояниях и реальные официальные Finder Gallery/Notes + HIG Split
views. Каждый даёт вердикт и издержки по варианту; Art Director ранжирует
пригодные. Accessibility Critic (medium) — readable text/art, focus и actual
keyboard menu в пределах смены фона. Прежние решения не пересматриваются.

Исправлять подтверждённые дефекты до показа; максимум3 итерации на finding,
после каждого изменения повторить затронутые функциональные и визуальные gates.
Совпадение dark/modal — критерий изоляции, а не причина менять их ради различий.
Итог: four-up, пара/один/полный интерфейс, исходные PNG, отчёты, проверенная
Ubuntu-сборка. Пользователь выбирает ART06.
