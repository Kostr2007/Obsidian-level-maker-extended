# Принятие ART-05 C и переход к ART-06

2026-11-07. Пользователь выбрал C с тёмной заливкой капсулы в тёмной теме,
затем поручил перейти к ART-06. Разрешение на оба шага дано; новый выбор цвета
внутри этой коррекции не требует дополнительного согласования пользователя.

## Первый шаг — принятие C

UI Builder (medium) меняет только dark fill/border выбранной капсулы и её
начальный выбор. Светлая C, её9×21 силуэт,15px wrapper, расширенный native
hit-testing, фокус/disabled/точный ввод/range/step/modes/CONFIG сохраняются.
Цель — тёмная спокойная поверхность с различимой границей, а не белый акцент
и не скрытая на фоне ручка. Уточнённый цвет — решение проекта, не Apple spec.
Другие A/B/D и ползунки остаются прежними. ART-01 A/02 A/03 A/04 B фиксированы.
Ожидания initial/fresh defaults в ART05 тесте обновляются на capsule; сам
исторический четырёхсторонний сценарий остаётся доступным.

После build/core и предварительных кадров Coordinator фиксирует код, а
Functional Tester (medium) снимает свежие48 ART05 кадров на чистом commit,
проверяет обязательные host-gates и реальные клавиши/видимые края/CONFIG/defaults.
Visual Critic (high) независимо проверяет C normal/focus/disabled/HiDPI/125%,
реальные dark/light PNG и исходные C из3dd5fa3. Accessibility Critic (medium)
оценивает границу/фокус/disabled/клавиатуру в пределах изменения цвета.
Светлая C должна сохранить исходный вид; dark становится темнее без потери
различимости. Дефекты исправляются до следующего production-шага.

## Затем ART-06

Только после подтверждения функциональной и визуальной проверки первого шага
UI Builder реализует четыре варианта светлого фона inline-инспектора.
Подготовка исследования/контракта допускается параллельно; production ART06
до приёмки C не изменяется. Во всех четырёх фиксированы принятые C и B-значки.
Исходное направление ART06 — дополнительная справочная область около рабочего
содержимого; меняется тон, не её структура. Конкретные варианты и матрица будут
записаны в ART06.md и art06-plan.md до реализации.

По итогам ART06 — чистый commit, новые кадры, независимые Functional Tester,
Visual Critic, Art Director и bounded Accessibility Critic. Пользователь
получает сравнение четырёх вариантов и делает окончательный выбор ART06.
