# ART-04: цветные значки навигации

**Решение пользователя, 2026-11-07: выбран B — цветные скруглённые подложки.**
Он становится начальным оформлением навигации в следующем прототипе ART-05.
Исходный A сохранён для воспроизведения сравнения. ART-01=A, ART-02=A и ART-03=A
сохраняются.

- **A:** исходные цветные контурные значки шести разделов боковой панели.
- **B:** собственные светлые глифы Obsidian на цветных квадратах со скруглением.

Эксперимент ограничен `--design-preview`. Смысл значков, порядок разделов,
геометрия строк и текста, выделение текущего раздела и клавиатурный фокус
сохраняются. Переключение действует в текущем сеансе; B — принятый начальный
вариант запуска. CONFIG, пресеты и обычный Studio не меняются.

Источник направления — [предложение ART-04](reports/2026-11-07-art-direction-next.md),
а не требование Apple к любому sidebar. Используется собственная графика.

[План, сравнение и условия проверки](reports/2026-11-07-art04-plan.md).

## Запуск и воспроизведение

```sh
./obsidian --design-preview
# Из распакованной Ubuntu-сборки:
./start.sh --design-preview
```

В меню команд (`Ctrl+Shift+P`) доступны варианты значков боковой панели A/B
для ART-04. B не меняет оформление значков панели инструментов.

```sh
./scripts/dev/build-linux.sh
python3 scripts/dev/check-art04.py
```

Сценарий использует производственный QML и снимает 28 кадров в новый каталог
`build/art04/`: light/dark, Geometry/Resources, небольшое окно, текст125%,
клавиатурный фокус и DPR1.5. Манифест содержит commit, hashes, геометрию,
данные и состояния; эта серия служит основой независимых заключений.
В GitHub Actions отдельный артефакт — `art04-comparison`.
