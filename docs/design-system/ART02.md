# ART-02: другая фактура настроек

**Решение пользователя, 2026-11-07: выбран A — существующая «зебра».**
Выбранный ранее ART-01 A также сохраняется. Эксперимент B оставлен для
воспроизведения сравнения; в ART-03 используются classic + zebra.

- **A:** текущая «зебра», исходная и включённая по умолчанию.
- **B:** общая поверхность группы с тонкими разделителями между строками.

Оба решения сохраняют подписи, значения и порядок параметров, высоты строк,
размеры контролов, заголовок и положение Seed. Другие группы остаются прежними.

```sh
./obsidian --design-preview
# Из распакованной Ubuntu-сборки:
./start.sh --design-preview
```

Откройте «Геометрию» и меню команд (`Ctrl+Shift+P`), затем выберите A или B
для ART-02. Это настройка текущего сеанса; CONFIG и пресеты не изменяются.
Новый запуск возвращает вариант A.

## Съёмка и проверки

```sh
./scripts/dev/build-linux.sh
python3 scripts/dev/check-art02.py
```

Сценарий использует настоящий производственный QML в отдельном QtTest-процессе.
Новый каталог в `build/art02/` содержит PNG, состояния, source/PNG hashes и логи.
Тема, viewport, DPI, масштаб текста, значения и фокус в парных кадрах совпадают.
Проверяются светлая/тёмная темы, увеличенный текст, небольшое окно, HiDPI и фокус.

Visual Critic и Art Director сравнили одинаковые кадры независимо; Functional
Tester проверил категории, клавиатуру, параметры и сохранение. После просмотра
результатов пользователь выбрал A.
