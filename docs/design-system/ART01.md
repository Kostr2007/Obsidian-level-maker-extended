# ART-01: альтернативное выделение ресурсов

**Решение пользователя, 2026-11-07: выбран исходный вариант A.** Он остаётся
оформлением ресурсов и вариантом по умолчанию. Эксперимент B сохранён только
для воспроизведения прошлого сравнения; в ART-02 он не используется.

```sh
./obsidian --design-preview
# Из распакованной Linux-сборки:
./start.sh --design-preview
```

В меню команд (`Ctrl+Shift+P`) доступны:

- **«Ресурсы: A · Классическое выделение»** — выбранное название с синей подложкой.
- **«Ресурсы: B · ART-01 (эксперимент)»** — обычный цвет текста, прозрачная подложка
  названия и усиленное начертание Inter того же размера.

Оба варианта сохраняют фон выбранной карточки, изображения, размеры и поведение
сетки/списка. Клавиатурный фокус обозначается отдельным контуром. Переключение
не записывается в CONFIG или пресеты и не затрагивает обычный Studio.

В рамках проверки исправлен ранее невидимый контур после перехода стрелкой:
клавиатурная навигация теперь передаёт соответствующий focus reason. Правка общая
для A/B; вход через мышь сохраняет прежнее поведение.

## Воспроизведение сравнения

```sh
./scripts/dev/build-linux.sh
python3 scripts/dev/check-art01.py
```

Нужны Qt Test, Xvfb и зависимости обычной сборки. Сценарий создаёт новый каталог
`build/art01/<commit>-<timestamp>/`, проверяет реальные состояния Qt и сохраняет
PNG, JSON, контрольные суммы и логи. Основные парные кадры:

| Тема | A | B |
| --- | --- | --- |
| Светлая | `light-classic-dpr1/ammo-grid.png` | `light-art01-dpr1/ammo-grid.png` |
| Тёмная | `dark-classic-dpr1/ammo-grid.png` | `dark-art01-dpr1/ammo-grid.png` |

Список — `ammo-list.png`, клавиатурный фокус — `ammo-keyboard.png` в тех же
каталогах. Дополнительные кадры проверяют hover соседней категории, лечение,
длинное название, текст 125%, небольшое окно и HiDPI. Снимки создаются из
производственного QML отдельным QtTest-процессом; это не нарисованные макеты.

В GitHub Actions та же матрица сохраняется как артефакт **art01-comparison**.
Функциональное заключение, сравнение Visual Critic и предпочтение Art Director
прилагаются к результатам конкретного прогона. После их просмотра пользователь
выбрал A; экспериментальные материалы B сохранены для истории сравнения.
